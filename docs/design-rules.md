# 设计契约（维护用）

方向：framed-sheet — 灰色框架 + 白色纸面。深度只靠一档色阶，静止元素不投影。

## 令牌（`src/renderer/styles.ts` 顶部 `.mr-root`）
- 亮：底 `#f4f4f1` / 纸 `#ffffff` / 字 `#16181a` / 弱字 `#5d5f60` / 线 `#e6e5df`
- 暗：底 `#121313` / 纸 `#191a1a` / 字 `#ececec` / 弱字 `#a2a4a4` / 线 `#2c2e2e`
- 强调只用一处：`--mr-accent`（亮 `#1b6c80` / 暗 `#6fc0d0`），占比 < 3%
- 圆角：纸面 16px，控件 6–8px；不许出现第二套圆角体系
- 行宽：`--mr-measure: 44rem`，正文纸面宽 = 行宽 + 左右内边距，永远不拉满列宽

## 布局
- 三列网格 `208 / 1fr / 192`，整块 `max-width: 1320px` 居中
- 纸面 `justify-self: center`：目录收起后纸面不跟着变宽
- 宽度行为：≤1180 收起目录列，≤960 文件树转抽屉（带遮罩）；抽屉与目录互斥

## 必须保持
- 窄屏只保留一个弹层（树 / 目录不能同时开）
- 断点回退后字号上限 18px，行高 1.6
- 新加控件优先复用现有按钮样式，不引入第三种描边或图标尺寸
- 动效克制：150–200ms，`prefers-reduced-motion` 下全部关闭

## 证据
- 截图用 `node scripts/shots.mjs <输出目录>` 生成，不入库
- 改造前的对照图随截图重拍，项目里不保存历史快照
